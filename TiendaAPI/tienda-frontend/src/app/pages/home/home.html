Quiénes somos

Una tienda pensada para mostrar catálogo real y navegación simple.

El objetivo de esta aplicación es servir como base para una tienda de productos con arquitectura sencilla, separación clara entre API y frontend, y un flujo de datos persistente en SQL Server.

Nuestra propuesta

Catálogo centralizado

Productos y categorías viven en la API y se leen directamente desde la base de datos.

Experiencia fluida

La página de productos incluye búsqueda en tiempo real y filtro por categoría.

Componentes standalone

El frontend está organizado con componentes independientes, servicios y rutas claras.

Base escalable

La estructura permite crecer después con autenticación, carrito o panel administrativo.
